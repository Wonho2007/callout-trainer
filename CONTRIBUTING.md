# Contributing

1. Clone the public repository; accept the collaborator invitation before pushing branches.
2. Read AGENTS.md and the full project brief.
3. Claim a lane issue and create a short-lived person-1/, person-2/ or person-3/ branch.
4. Work within the paths in docs/TEAM.md. Coordinate shared settings and schemas before changing their consumers.
5. Run python tools/check_repo.py, plus relevant actual engine checks once available.
6. Update docs/HANDOFFS.md with facts and open dependencies.
7. Open a small PR using the template; request teammate review and resolve contract changes before merging.

Never commit credentials, .godot/ caches, export credentials, build output, recordings, participant data, proprietary game files or reference footage. Store runtime logs in Godot user://. Only deliberately sanitized, explicitly synthetic fixtures belong under examples/.

No blanket permission to redistribute this repository is granted by the absence of a license. Decide the project license and third-party asset terms before publication.
