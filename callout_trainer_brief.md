# Callout Trainer brief

The current product description is [docs/PROJECT_DESCRIPTION.md](docs/PROJECT_DESCRIPTION.md).
The implementation/resume source is [docs/PERSON2_HANDOFF.md](docs/PERSON2_HANDOFF.md).
Read [AGENTS.md](AGENTS.md) before changing code.

Build a first-person, voice-only communication practice game using information-limited
teammates. Local speech recognition and grounded interpretation turn player comms into
delayed, validated reports/commands and visible physical reactions. Preserve a fair
deterministic fallback. The measured sprint configuration uses LLM interpretation with
deterministic goal selection; experimental model goals are not accepted.

Current scenario: a separate authored seven-region plant hold. Unknown enemies stay
absent until the annotation first locates them (+23s for the current four). Do not guess
starts from utility effects, automate the human's reference beats or force recorded kills.
Source metadata and exact geometry remain unverified; label adaptations honestly.

Required safeguards remain: shared player/bot physical rules; smoke/flash restrictions;
reaction delay; evidence ownership/availability; private truth separation; scenario
validation; visible fallback reasons; offline-capable delivery and a backup video.
Voice is core. The player must be able to report after death while a teammate survives.

Fully accept valid delivered player testimony even when wrong; preserve uncertainty and
physical/validation limits without a credibility/history feature. The current belief
implementation still has an alignment gap; document it rather than claiming completion.

The eventual product still includes communication grading, truth-versus-belief debrief,
belief-only counterfactual and honest comparison/evaluation. These are deferred until
the core works, not implemented or permanently removed. Outcome counterfactuals remain
approximate stretch work. A small pilot must not be presented as proof of transfer.

Godot 4.4.1 stable, local/free components, no training or paid API requirement. No game
client access, ripped assets, replay scraping, invented pro facts or unverified benefit
claims. Use synthetic/authored data openly where source details are unresolved.

The superseded long brief, research motivation, PDF traceability and old three-person
timelines are preserved via the [historical index](docs/ARCHIVE.md). They are background,
not current scheduling, ownership or permission instructions.
